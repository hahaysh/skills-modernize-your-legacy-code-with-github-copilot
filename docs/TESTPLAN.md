# Student Account System Test Plan

This plan captures the observable behavior of the current COBOL application. It is intended for business stakeholder validation and as a basis for future Node.js unit and integration tests.

Unless a test says otherwise, compile the application, start a new process, and confirm that no transactions have yet been performed. Monetary output uses the COBOL `PIC 9(6)V99` display format, such as `001000.00`.

## Stakeholder Decisions Before Node.js Implementation

The COBOL application does not define safe, user-facing behavior for malformed or nonnumeric input, negative amounts, more than two decimal places, or arithmetic above the maximum `999999.99` field value. These should not be assigned expected results from the legacy code alone. Business stakeholders should define validation and error-handling requirements for these cases before they become Node.js acceptance tests.
